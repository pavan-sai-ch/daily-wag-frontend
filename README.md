# The Daily Wag - Frontend

## Quick Start (Docker)

### 1. Prerequisites
Ensure **Docker Desktop** is installed and running.

### 2. Configuration
Check `src/api/api.js`. Ensure the `baseURL` points to your running backend.
* **Local Docker:** `http://localhost:8080/api`

### 3. Run the App
Run this single command in your terminal to build and start the frontend container:

```bash
docker-compose up --build
